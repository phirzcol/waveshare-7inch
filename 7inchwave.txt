================================================================================
HARDWARE OVERVIEW
================================================================================

SoC:            ESP32-P4NRW32 (dual-core RISC-V HP 360MHz + single-core LP 40MHz)
WiFi/BT:       ESP32-C6-MINI-1 via SDIO (WiFi 6 / BLE 5)
Flash:          32MB (QIO, 80MHz)
PSRAM:          32MB (200MHz, hex-SPI)
Display:        7" IPS 1024×600, MIPI-DSI 2-lane, EK79007 controller
Touch:          GT911 capacitive (I2C addr 0x5D)
Audio DAC:      ES8311 (I2C addr 0x18)
Audio ADC:      ES7210 echo cancellation (I2C addr 0x40)
SD Card:        SDMMC 4-bit (SDIO 3.0)
USB:            Type-A OTG 2.0 HS port
Camera:         MIPI-CSI 2-lane (OV5647 compatible)
Battery:        MX1.25 connector (VDD_BAT pin, no fuel gauge IC)
RTC Battery:    CR1220 holder (rechargeable 3V-3.3V only)

================================================================================
PIN ASSIGNMENTS
================================================================================

I2C Bus (shared):
  SCL = GPIO8
  SDA = GPIO7

I2S Audio:
  MCLK = GPIO13
  SCLK = GPIO12
  LRCK = GPIO10
  DOUT = GPIO9 (to codec)
  DIN  = GPIO11 (from codec)
  PA   = GPIO53 (power amplifier enable, active high)

Display (MIPI-DSI):
  Backlight = GPIO32 (inverted: LOW = bright)
  Reset     = GPIO33
  DSI PHY LDO = channel 3, 2500mV

Touch (GT911):
  Uses I2C bus (GPIO8/7)
  Reset = GPIO23 (active low, directly connected)
  INT   = NC (not connected on this board)

SD Card (SDMMC 4-bit):
  CLK = GPIO43
  CMD = GPIO44
  D0  = GPIO39
  D1  = GPIO40
  D2  = GPIO41
  D3  = GPIO42
  Power: LDO channel 4

ESP-Hosted SDIO (WiFi C6):
  CLK       = GPIO18
  CMD       = GPIO19
  D0        = GPIO14
  D1        = GPIO15
  D2        = GPIO16
  D3        = GPIO17
  Reset     = GPIO54
  Data Ready = GPIO6 (optional, not used in current config)

UART (PH2.0 connector):
  TXD = GPIO26
  RXD = GPIO27

Console UART (USB-Serial/JTAG):
  TX = GPIO37
  RX = GPIO38

USB OTG (Type-A):
  Standard USB 2.0 HS, no GPIO config needed

================================================================================
I2C DEVICE MAP (confirmed by scan)
================================================================================

  0x18 = ES8311 (audio codec)
  0x40 = ES7210 (echo cancellation ADC)
  0x5D = GT911 (touch controller)

  No power management IC, no fuel gauge.
  Battery monitoring via ESP32-P4 brownout detector (VDD_BAT pin, threshold-based only).

PARTITION TABLE (32MB Flash, Dual-Boot)
================================================================================

  Name      Type    Offset      Size
  -------   ----    ----------  --------
  nvs       data    0x9000      16KB
  otadata   data    0xd000      8KB      ← Required for dual-boot switching
  phy_init  data    0xf000      4KB
  factory   app     0x10000     4MB      ← Main tablet app
  ota_0     app     0x410000    4MB      ← VNC client
  storage   data    0x810000    10MB     ← FAT filesystem (SD card fallback)

================================================================================
FLASH PROCEDURE
================================================================================

1. Put device in boot mode: Hold BOOT, press RESET, release BOOT
2. Flash main app (from test_wifi_audio/):
     idf.py -p COM23 flash
   This writes: bootloader + partition table + otadata + factory app

3. Flash VNC client to ota_0 (from vnc_client/):
     python -m esptool --chip esp32p4 -p COM23 -b 460800 \
       --before=default_reset --after=hard_reset \
       write_flash --flash_mode dio --flash_freq 80m --flash_size 32MB \
       0x410000 build\vnc_client.bin

   *** DO NOT use "idf.py flash" from vnc_client/ — it overwrites factory! ***

4. Press RESET to boot into main app (factory is default)

================================================================================
KNOWN ISSUES & WORKAROUNDS
================================================================================

1. ESP_IDF_VERSION env var: Must be set to "5.5" before build or esp_wifi_remote
   Kconfig orsource fails silently.

2. ESP-Hosted SDIO crashes under heavy WiFi load: Reduce TX/RX queue sizes to 10.
   Queue size 20 causes hard resets during VNC streaming.

3. LVGL 64KB built-in pool: Default CONFIG_LV_USE_BUILTIN_MALLOC with 64KB pool
   is too small for settings UI + keyboard. Must use CONFIG_LV_USE_CLIB_MALLOC=y.

4. HW JPEG decoder: Rejects images with dimensions not divisible by 8.
   Use jpeg_decoder_get_info() to check before decoding.

5. iPazzport USB HID: Sends 8-byte reports with report ID 0x01, 16-bit X/Y.
   STALLs on SET_IDLE and SET_PROTOCOL — ignore these errors.
   esp_lvgl_port_usbhid.c patched to handle this format.

6. WiFi + Audio conflict: ESP-Hosted SDIO polling competes with SD card SDMMC DMA.
   Don't run WiFi during audio playback. VNC and audio cannot coexist.

7. Backlight GPIO32 inverted: LOW = bright, HIGH = dim/off.

8. sdkconfig deletion: Delete sdkconfig when changing sdkconfig.defaults.
   It regenerates on next build. Never edit sdkconfig directly.

9. Battery monitoring: No fuel gauge IC. Only ESP32-P4 brownout detector on VDD_BAT.
   Threshold-based (Full/Low/Critical), not percentage. Max detection 2.9V.

10. Dual-boot otadata: Partition table MUST include otadata (type=data, subtype=ota)
    or esp_ota_set_boot_partition() has no effect.

================================================================================
USB PORTS
================================================================================

Port 1 (Type-C, "USB 1.1 FS"): USB-Serial/JTAG built into ESP32-P4
  - Shows as "USB device" in Windows Device Manager
  - Used for flashing (COM23 in this setup)
  - Console UART output (GPIO37/38)

Port 2 (Type-C, "USB TO UART"): External USB-UART bridge chip (CH340/CP2102)
  - Shows as "Serial port" in Windows Device Manager
  - Same console output as Port 1
  - Can be used to feed serial data to external monitor (CYD)

Both ports output the same serial log data.

================================================================================
BATTERY MONITORING (ESP32-P4 Brownout Detector)
================================================================================

VDD_BAT pin connects to battery via MX1.25 connector.
No external fuel gauge — uses internal brownout detector comparators.

Registers:
  LP_ANALOG_PERI_VDDBAT_BOD_CNTL_REG — bit 0: undervoltage flag
  LP_ANALOG_PERI_VDDBAT_CHARGE_CNTL_REG — bit 0: charge undervoltage flag

Thresholds (VBAT_BOD): 2.0V to 2.7V in 0.1V steps
Thresholds (VBAT_CHARGER): 2.2V to 2.9V in 0.1V steps

Logic:
  Both flags 0 → Battery OK (above 2.9V)
  Charge flag 1, BOD flag 0 → Battery Low (2.5V-2.9V)
  Both flags 1 → Battery Critical (below 2.5V)

For LiPo (3.0V-4.2V): will always show "OK" until nearly dead.
Useful as safety cutoff warning, not as percentage gauge.
